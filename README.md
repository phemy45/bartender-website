# Bartender Website

A responsive bartender business website built using HTML, CSS and JavaScript.

## Live Website
https://phelixthebartender.netlify.app/

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Features
- Responsive website design.
- Display of bartender services and offerings.
- Visual presentation of the business.
- User-friendly navigation.
- Contact information for potential clients.

## Project Purpose
This project was developed to establish an online presence for a bartender business and showcase my frontend web development skills.
